# Virtual Functions v1.1

フローティングウィンドウ型のファンクションキーアプリケーションの実行可能ファイル版

## 📦 ビルド済みファイル

### 実行ファイル
- `VirtualKeyboard_v11.exe` (28MB) - メインの実行可能ファイル
- すべての依存関係を含む単一実行ファイル

### 設定ファイル
- `config.json` - ボタン設定とウィンドウ設定

## 🚀 使用方法

### 1. 実行
```bash
# 実行ファイルをダブルクリックまたは
VirtualKeyboard_v11.exe
```

### 2. 基本操作
- アプリケーション起動でフローティングファンクションキーが表示
- 右クリックでコンテキストメニューを表示
- 設定やボタン管理でカスタマイズ可能

### 3. 主要機能
- **フローティングウィンドウ**: 常に手前に表示されるファンクションキー
- **ボタンカスタマイズ**: ボタンの追加・削除・移動が可能
- **レイアウト切替**: 横並び⇔縦並びの切替
- **テーマ切替**: ライトモード⇔ダークモードの切替
- **フォーカス管理**: キー送信後の元ウィンドウフォーカス復元
- **遅延入力モード**: 3秒遅延でのキー送信

## 📁 配布ファイル構成

```
VirtualFunctions_v1.1/
├── VirtualKeyboard_v11.exe    # メイン実行ファイル
├── config.json                # 設定ファイル（必須）
└── README_v1.1.md            # このファイル
```

## ⚙️ システム要件

- **OS**: Windows 10/11 (64-bit)
- **RAM**: 最小 512MB（推奨 1GB以上）
- **ディスク**: 約50MB の空き容量
- **権限**: 通常ユーザー権限（管理者権限不要）

## 🔧 設定について

### config.json の主要項目
```json
{
  "floatingWindow": {
    "position": {"x": 100, "y": 100},
    "layoutDirection": "horizontal",
    "buttons": [
      {"key": "ctrl+c", "label": "Copy"},
      {"key": "ctrl+v", "label": "Paste"}
    ]
  },
  "keyDelay": {
    "delayMs": 3000
  }
}
```

## ⚠️ 重要な注意事項

1. **設定ファイル**: `config.json` は実行ファイルと同じフォルダに配置必要
2. **セキュリティ**: 一部のアンチウイルスソフトが誤検知する場合があります
3. **初回起動**: 初回起動時は展開に数秒かかる場合があります
4. **ウィンドウフォーカス**: 他のアプリケーションに対してキーを送信するため、対象アプリがアクティブである必要があります

## 🐛 トラブルシューティング

### 起動しない場合
1. `config.json` が同じフォルダにあるか確認
2. Windows Defender の除外設定を確認
3. 管理者として実行を試行

### キーが効かない場合
1. 対象アプリケーションがアクティブか確認
2. セキュリティソフトの設定を確認
3. 遅延入力モードを試行

### パフォーマンス問題
1. タスクマネージャーでメモリ使用量を確認
2. 他のアプリケーションとの競合を確認
